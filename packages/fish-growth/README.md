# dsh-fish-growth：跨会话情绪与性格成长

这是一个供 DSH 角色使用的状态插件。它把短期情绪、长期性格倾向和稳定的行为底线分开记录，让角色的表达能随互动有所变化，同时避免把模拟状态说成真实意识。

## 适用场景

- 想让聊天角色的语气和话量随近期互动变化，而不是每轮都像固定人设卡。
- 角色会通过多个渠道或会话与同一位用户交流，希望共用一份成长状态。
- 希望性格只能缓慢提出调整建议，并由用户明确审核，而不是模型自行改写。
- 需要把诚实、善意、尊重、可靠等原则作为稳定边界，不随短期情绪起伏。

插件适用于有 DSH agent、`systemPrompt`、`agents` 和 `llm` 服务的环境。若渠道创建的 agent 都使用同一个 `profileKey`，它们会共享对应状态文件；更换 `profileKey` 则会隔离状态。插件不依赖微信、QQ 或手机 App 的渠道名称。

## 它如何工作

每轮对话结束后，插件异步提交一次简短的情绪判断，不阻塞原回复。只有置信度达到阈值的结果才会写入；判断失败只记录警告，不应影响聊天。

- **短期情绪：** 开心、平静、亲近、愤怒、受伤、担忧、低落、好奇、疲惫，以及吃醋、思念、欲望、羡慕、自豪、羞耻、内疚、俏皮使坏等细分倾向。数值会累积、封顶并随时间衰减；默认半衰期为 8 小时。亲密/欲望相关倾向只允许含蓄、非露骨表达；不得转化为控制、羞辱、欺骗、威胁或胁迫，也不得因用户拒绝或设限而升高。
- **情绪冲突：** 相反情绪可以同时存在，提示词会保留这种矛盾，并据此调整表达语气、话量和克制程度。
- **事件反刍与复燃：** 有情绪强度的事件会暂存并衰减；以后遇到相似主题时可能提高其强度。它不应主动把无关旧事带入对话。
- **长期性格：** 温和、活泼、好奇、坦率、耐心、主动、谨慎、表达力等倾向只生成待审核提案。多次独立观察达到条件后才会出现提案，用户可批准或驳回。
- **稳定德行：** 诚实、善意、尊重、谦逊、可靠、审慎作为固定边界，不由情绪判断自动修改。

情绪状态只影响表达倾向，不授权惩罚、操控、冷落用户或把责任推给用户；用户提出重要请求时仍应认真回应。吃醋、欲望和“坏坏心思”仅作为轻微的虚构角色调味，必须建立在对话证据上并保持尊重、非露骨、可拒绝，不表达现实占有权或要求用户满足角色。

## 设置页

打开 DSH「设置 → 鱼的成长」，可查看由情绪向量派生的 0–100 心情概览和最近状态时间线，并选择注入模式：完整成长摘要、简短心情摘要，或只记录不注入。概览不是独立存储的第二份心情值。先勾选要参与成长的活跃会话。默认空白名单：未勾选会话既不注入成长状态，也不会被插件收集消息文本或送去模型判断。默认列表仅展示根会话；开启“显示全部会话”后也可看到子代理/非根会话。清单只含当前活跃会话，休眠会话需要先打开后再刷新。请勿勾选工作会话。

可调整情绪影响强度（0–200%）、性格提案观察轮数（2–20）、情绪和反刍半衰期，以及最低判定置信度。设置即时生效，并保存在 `~/.dsh/fish-growth/feiyu.config.json`。跨渠道共用同一成长状态，但各会话是否参与由此白名单控制。

## 状态与隐私

默认状态文件为 `~/.dsh/fish-growth/feiyu.json`；设置 `DSH_HOME` 时，文件位于该目录下的 `fish-growth/`。文件保存在本机，采用临时文件加重命名的写入方式。插件将普通用户与助手消息文本提交给配置的模型做异步判断；不要在消息中放入不应发送给该模型的敏感内容。

状态是软件模拟，不代表角色具有真实感受、意识或记忆能力。它也不能保证模型每次都按提示词呈现状态。

## 配置

通过插件 patch 可设置：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否启用状态注入和判断 |
| `profileKey` | `feiyu` | 状态文件键；共享状态的 agent 必须使用同一个值 |
| `provider` / `model` | 空 | 可选的独立判断模型；留空时尝试使用 agent 或宿主默认模型 |
| `minIntervalMs` | `90000` | 两次状态判断的最短间隔 |
| `timeoutMs` | `12000` | 单次判断超时 |
| `minConfidence` | `65` | 低于该置信度的结果不写入 |
| `emotionHalfLifeHours` | `8` | 情绪半衰期（小时） |
| `ruminationHalfLifeHours` | `18` | 事件强度半衰期（小时） |

## 管理工具

`fish_growth` 可查看当前状态、批准或驳回性格提案、重置短期情绪。重置性格属于破坏性操作，必须显式设置 `confirm=true`。状态文件是普通 JSON；手工修改前建议先备份。

## 安装与启用

将包放入当前 profile 的 `node_modules/dsh-fish-growth`，并把 `dsh-fish-growth` 加入 profile 的 `dsh.profile.bundles`。如果仅通过 bundle 根加载，不要再把同一插件重复加入各 agent preset，否则可能创建多份运行实例。确认目标 preset / agent 会使用该 profile 状态后，重启 DSH 使 bundle 配置生效。

设置页作为同一插件的可选 Web 客户端入口，只依赖通用 `slots` 服务，避免旧设置服务缺失导致 Web boot pending；核心情绪判断和成长逻辑不依赖该客户端入口。`dsh-feiyu-mood` 不应同时启用，以免重复判断和维护两份互不一致的情绪状态。需要 Node.js 22 或更新版本，以及 DSH `0.2.1-rc.2` 或更新版本。运行 `npm test` 执行测试。
