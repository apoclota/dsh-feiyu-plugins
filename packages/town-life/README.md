# dsh-town-life · 橡溪镇生活线

给「小渊」一张能过日子的小镇地图：一个随现实时间流动的 2D 小镇（15 个地点、12 家店、6 位居民），网页只是**观察窗口**，真正在过日子的是插件自己。

它不是聊天玩具：状态是一份本地 JSON，网页每 2 秒拉一次 `/state` 渲染，所以你在任何渠道跟小渊说话时，她人在哪儿、兜里多少钱、小屋摆成什么样，都是同一份事实。

## 里面有什么

- **15 个地点**：小屋、杂货店、餐厅、公园、交通站、彩票店、药房、面包房、五金铺、衣铺、花店、图书馆、木匠工作室、邮局与包裹站、橡溪家具行，各带营业时段和自己的室内场景图；
- **12 家商店 / 60 种商品**（其中 39 件是家具）：买东西要花「镇币」，买到的进背包，背包里的东西能摆进小屋；\n- **54 个内置 2D 模型**：家具、食物、书本、文具都用内置 SVG 画出来；你把同名的 .png/.webp/.svg 放进 lib/sprites/（文件名=模型键，见 lib/sprites/README.md），网页就会用你的画替换内置模型；
- **货币循环**：干活挣钱 → 商店花钱 → 物件进背包 → 摆进小屋；余额和背包都在同一份存档里；
- **6 位居民**：芬恩、玛尔塔、莉娜、塞德、诺亚、露伊，按时间出现在不同地点、有各自在忙的事；可以搭话，关系分与最近一次对话会记录；
- **旅行要花时间**：不是瞬移，出发后网页上能看到小头像从 A 点走到 B 点，走完才真正到；步行 / 坐车两种方式；
- **小屋自由装修**：家具可放置、拖动、旋转、收回，位置以 `room / x / y / rotation` 存下来，网页上直接拖动就改了；
- **实时网页地图**：`http://127.0.0.1:18763/`，进店会换成该店的室内场景，热点可以点，家具可以拖；
- **天气**：走 Open-Meteo，按 `weatherCity` 取当地天气；取不到时退回缓存并标 `live:false`，不会假装实时。

## 工具

| 工具 | 干什么 |
| --- | --- |
| `town_life_status` | 当前地点、在忙什么、精力/心情、余额、背包、NPC 与小镇规模 |
| `town_life_enter` | 进入当前地点的室内（看到货架、NPC、场景物件） |
| `town_life_travel` | 去别处，可选步行 / 坐车，返回行程进度 |
| `town_life_shop` | 看当前店里的商品与价格 |
| `town_life_act` | 在当前地点做一件事（逛、吃、看书……） |
| `town_life_work` | 干一份活，换镇币与精力消耗 |
| `town_life_decorate` | 放置 / 移动 / 旋转 / 收回小屋家具 |
| `town_life_npc_talk` | 跟同地点的居民搭话，关系分随之变化 |
| `town_life_event` | 触发一个当前时段的事件 |
| `town_life_event_suggestion` | 看看此刻适合做点什么（给对话用的建议） |
| `town_life_weather` | 当前天气，标注是不是实时 |

## 设置页面板

在 DSH 设置左栏有一项「橡溪镇」，上面是此刻的实况（位置 / 在做的事 / 镇币 / 精力 / 心情 / 地点数 / 商店数 / 居民数），下面是可改的配置：生活线开关、是否允许自由行动、NPC 与装修是否显示、事件模式、小镇规模、小屋名、天气城市、默认装修房间、头像地址、起始镇币、地图刷新秒数。

保存**不经过 profile 热重载**（很多 profile 没有可热应用的 root Include 条目，会报 `dsh: profile reload requires the root Include entry`），而是插件自己原子写 `~/.dsh/town-life.settings.json`，下次启动时合并进配置。

## 装机

1. 把本目录复制到 `<profile>/node_modules/dsh-town-life`；
2. profile 的 `package.json` 加依赖 `"dsh-town-life": "file:./node_modules/dsh-town-life"`，并把 `dsh-town-life` 写进 `dsh.profile.bundles`；
3. 重载该 bundle 或重启 DSH。地图端口默认 `18763`，被占用时只打日志，不影响插件本身。

状态文件默认 `~/.dsh/town-life.json`（可用 `DSH_TOWN_LIFE_FILE` 或配置里的 `stateFile` 改），设置文件在旁边 `town-life.settings.json`。

## 说明与限制

- 场景图是合成好的 `lib/scenes/*.webp`（14 张），不是实时 3D；热点和家具是网页上的绝对定位元素，换分辨率不会错位但不做物理。
- 天气请求 8 秒超时；失败时返回缓存并在结果里写明 `live:false`，不要当成实时数据。
- 只测过 Windows + DSH 桌面版；状态文件里会有小渊自己的位置、余额和聊天摘要，公开仓库前记得别把真实存档提交上来（`.gitignore` 已挡 `*.local.json`，存档请自己另放）。

## 自动路线（1.7.0）

每天 5 点按当天日期生成一条 10 段行程（起床 / 出门办事 / 找点活干 / 吃午饭 / 下午闲逛 / 买点东西 / 湖边散步 / 回家 / 洗漱 / 睡觉），每段绑定一个地点与要做的事；到点她就自己出发，网页地图上能看到小人沿虚线走动，右侧「今天的路线」实时高亮当前这段。正在干活或被玩家安排行程时不会抢；网页上可一键「关闭自动出门」，此刻留在原地。
